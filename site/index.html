03 / Privacy contract

The boundary is visible.

Watches your clipboard locally. Nothing leaves this machine unless it is error-shaped text resolving to a Git repository you explicitly allowlist. If admitted, the copied error is sent verbatim to Codex using GPT-5.6 Sol. Premonition does not redact it, store it or auto-apply the result. You always review the patch first.

Stays local

Ordinary clipboard content

Prose, URLs, snippets and unsupported shapes stop before the executor starts.

Can leave

Admitted copied errors

After gate, allowlist and cap admission, the error is sent verbatim. v0.1 has no secret-redaction pass and makes no claim about provider retention.

05 / Demo guide

What to watch for.

The useful evidence is in what Premonition refuses to do.

  1. 01Copy ordinary text.

    Nothing starts. Nothing leaves.

  2. 02Copy a traceback.

    The admitted loop becomes visible.

  3. 03Review the patch.

    Applicability is shown without a correctness claim.

  4. 04Dirty the worktree.

    Apply blocks; Copy Patch remains available.

  5. 05Disable networking.

    Labelled fixture replay still traverses the real local safety spine.
